Qudas 0.2.2 の変更点
================================

リリース日: 2026-05-15（詳細はリポジトリ内 ``CHANGELOG.md`` の **[0.2.2]** を参照）

本リリースでは **新機能の追加はありません**。ドキュメント（Sphinx / README）の更新と、既存機能に影響しない範囲の修正のみです。

ドキュメント
------------

- トップページの説明と toctree の整理、概念図の差し替えとキャプションの更新。
- ``README.md`` のアーキテクチャ説明・インストール例・図の参照パスを更新。
